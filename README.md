# Mother's Day Tribute Blog

A modern, responsive blog platform built with Next.js and Tailwind CSS to celebrate and honor mothers through inspiring stories and articles.

## Features

- 🎨 Modern and responsive design
- 📱 Mobile-first approach
- 🎭 Interactive carousel for featured stories
- 📚 Category-based article filtering
- 🔍 Article search functionality
- 📖 Dynamic article pages
- ⚡ Fast page loads with Next.js
- 🎯 SEO optimized

## Tech Stack

- Next.js 14
- TypeScript
- Tailwind CSS
- React
- Next.js Image Optimization
- Next.js App Router

## Getting Started

### Prerequisites

- Node.js 18.0 or later
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/yourusername/mothers-day-blog.git
cd mothers-day-blog
```

2. Install dependencies:
```bash
C:\Program Files\nodejs\npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.
